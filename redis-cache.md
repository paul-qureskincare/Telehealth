1. У нас есть embed в который вставляется на главную страницу. Все инструкции находятся в файле embed.md
2. У нас есть подключение к Redis. Все инструкции находятся в файле .env 
3. Я хочу добавить новый путь в роутере, который бы осуществлял проксирование запроса. 
4. Через этот новый путь должен загружаться JavaScript от Embed. При первой загрузке страницы, когда кэша нет, должен вызываться нативный Embed и заполнять кэш в Redis. При второй и последующих загрузках должна осуществляться проверка кэша. Если он есть, то содержимое в контейнер должно выводиться из Redis. 
5. Время жизни кэша 15 минут. После этого происходит инвалидация, то есть опять запрос к нативному Embed, чтобы получить данные и перезапись кэша. 
6. Все данные из кэша должны быть вставлены в контейнер Embed. Важно, чтобы данные вставлялись не только статичные, то есть HTML, но чтобы еще корректно работал JavaScript код. Внимательно изучи, какой лучший механизм использовать для вставки этих данных. 
7. После того, когда кэш готов, ты должен перезапустить сервер, открыть браузер, открыть страницу в нем, убедиться, что первый запрос идет к нативному Embed и заполняется кэш. Потом надо перезагрузить страницу и убедиться, что данные в контейнер загружаются уже из кэша.
